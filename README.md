# snake-u
Snake-U is my spin on snake, with bonus features to innovate on classic snake gameplay.

<img width="1313" height="938" alt="image" src="https://github.com/user-attachments/assets/47287e31-c110-4e0d-bc75-0b052cd369d4" />

*This is the main menu page. There are a variety of options, including normal and timed mode, as well as a sign in / account creation section.*

<br>

The game is entirely web based, written in JavaScript. To add variety in gameplay, I added a difficulty slider and additional modes. There's EXTREME mode for anyone looking for more of a challenge!

<br>

<img width="1336" height="939" alt="image" src="https://github.com/user-attachments/assets/88236671-f8ee-4adf-b486-ebd9da86081a" />
